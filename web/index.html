sign in with user token

the main way to sign in: paste your discord user token. an oauth access token (from an "authorize" button) is rejected by the gateway - only a raw user token works.
don't have one? on your pc, open the token helper page - it prints your token and copies it to the clipboard for you. (devtools on a phone is iffy.)
token helper page http://…:8642/pc.html
other sign-in methods (discord login · qr · email)

sign in with discord

opens discord's own login page in the ps5 browser. because that page runs on discord.com, captcha works there natively. discord then redirects the token back to this app.

sign in with qr

open discord on your phone, settings → link with other devices, then scan this. no password ever touches the ps5.

sign in with email

captcha may appear above if discord asks for one. if it won't load, paste a token instead.
