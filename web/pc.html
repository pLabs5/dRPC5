1 - get your token

a token is a long string that authenticates as you. treat it like a password: anyone holding it controls your account.
  1. on this device open discord.com/app (or the discord desktop app) and log in.
  2. open devtools: F12 / Ctrl+Shift+J / Cmd+Option+J and go to the console tab.
  3. paste this and press enter:
it prints your token and copies it to the clipboard. this calls discord's own getToken(), so it works even where localStorage.token is hidden. if it logs no token found, your clipboard was not touched - use the network tab below.
note: recent discord builds store localStorage.token as a json object ({"locale":...,"ast":[]}) rather than the raw token, so that fallback rarely applies - the getToken() path above is the one that works.
fallback if it says "no token found": F12 → application → local storage → https://discord.com → look for the token key. it only appears once you turn on device emulation first (Ctrl+Shift+M / Cmd+Shift+M). copy the value without the surrounding quotes.
  1. open discord.com/app and log in.
  2. open devtools (F12) and go to the network tab.
  3. in the filter box type users/@me and refresh the page.
  4. click the first users/@me request, open headers → request headers.
  5. find authorization: - the value after it is your token. copy it.

2 - paste it here

stored on the ps5 at /data/drpc5/token. presence reconnects within about 10 seconds. the pills above update on their own.
an oauth access token (from an "authorize" button) will be rejected by the gateway with error 4004. only a raw user token works.

on the ps5 itself

if you would rather not type: open http://127.0.0.1:8642 in the ps5 browser and use the sign in tab - it takes the token too. discord login, qr and email are tucked under other sign-in methods.
